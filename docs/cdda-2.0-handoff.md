# CDDA preparation for Tyrfing 2.0

The World Party candidate updates the installed experimental CDDA set with
a matching menu and isolated `ce-cdda-wwp.kui`. It is not the complete public
2.0 distribution. The source archive and cumulative patch use base
`1aa16821209bcd9a186c344dcba6223afee7f420`; the final package records its
clean source commit and every installed payload identity. Merge that source
into the Tyrfing preparation branch and retain concurrent mainline changes.

World Party adds a fourth exact CE kernel/native-sound implementation. It
can route other applications with the same admitted kernel and runtime
contract, independently of title strings and supported track geometry.
Unknown kernels and native executables remain refused when CD music is On;
turning it Off retains the ordinary game route. Experimental describes
untested combinations, and never substitutes for a missing runtime adapter.

The menu offers the CD music option for high-density AUDIO candidates.
Backend selection follows the inspected native/WinCE identity. Multiple
manual backend choices would not establish missing memory or voice ownership.
Existing supported Toy/MDK2 native families remain available. Quake III has
an active GINSU chain that overwrites the current native worker and uses a
different allocator; its CD music requires further implementation.

The incremental World Party delivery preserved the accepted Armageddon module,
SHA256 `3c39d5b4e149b4ed911f7d4cf1fd19ea750f94a0a783b149cf4c5357cd36651a`.
The later full RC14 packager rebuilt all four modules instead. Its rebuilt
Worms module enables broader application discovery; it is not the exact accepted
binary. The worker-budget/RAM-copy corrections remain enabled, while rebuilt
module acceptance still needs a console run. See the
[artifact audit](release-v2.0-cdda-acceptance-audit.md) for exact hashes and scope.

World Party build `b08802f8945f` has an owner-reported successful console run.
The supplied diagnostic video records two successful native starts 33 seconds
apart, no recorded gaps/recoveries, and no guard, bind or audio fault. It does
not show live gameplay, audible continuous music or the image's raw/cooked
geometry. See the [scoped acceptance record](evidence/world-party-status-restart-2026-10-15.md).
Hardware evidence and launch admission have separate identifiers; this result
does not upgrade the existing Toy evidence slot or mark other versions Tested.

The owner accepted the World Party replacement and requested its mainline
merge. World Party remains Experimental for 2.0; broader hardware compatibility
testing can follow later. Merge the optional module and matching
menu into the existing Tyrfing release set, with their source/provenance, and
describe the actual limits in its release notes. Keep G1 hardware experiments
out of this feature merge. Public publishing is a separate release step.

The startup helper accepts BIN/CUE and GDI for analysis. This does not add
CUE CDDA launch support. The new batch WinCE inventory groups exact stored
module/section/firmware identities; those groups help prioritize reviews
without declaring additional titles compatible.
