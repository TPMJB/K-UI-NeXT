# Library compatibility table

One row per game in the owner's library uploads, generated by
[`tools/library_compat_table.py`](../tools/library_compat_table.py). It runs
each native startup through the production checks the Background (X/Y) launch
uses, in the launcher's own order, and joins the console results already
recorded in
[`evidence/library-console-results.json`](evidence/library-console-results.json).

- **Background X/Y + virtual VMU:** the compact Background module (72 KiB VMU
  worker, 284 KiB lease) admits the game: its structural gates pass, or the
  game has a reviewed fixed arena, and it has the SDK SCI family the reader's
  interrupt route needs.
- **Without VMU:** when Background refuses, New falls back to the standalone
  reader if the SDK SCI family exists.
- **Blocker:** the first gate that refuses.
- Ordinary Standard launches with VMU Off have no static gate, so every native
  game is expected to boot that way; this table is about the added services.
- Static gates are necessary, not sufficient. "Known limit" marks a blocker the
  roadmap records that the static model does not check.

## What it says

- **16 of the 21 native startups pass the Background virtual-VMU gates.**
  Console-confirmed among them: Code: Veronica, Crazy Taxi 2, Jet Grind Radio,
  House of the Dead 2, Time Stalkers and Elemental Gimmick Gear. Never tested
  with the virtual VMU on console: Evolution, Evolution 2, Rayman 2, Skies of
  Arcadia, Sonic Adventure 2, Power Stone 2 (from SD) and Berserk (retest with
  its card in A1). These are console tests, not code work.
- **The static model is optimistic for Sonic Adventure and Silver.** Both pass
  every gate, but the roadmap records blockers it does not model (executable
  loader and exit lifetime; executable reclamation, exit consumers and locks).
  Those checks belong in the host model so the table stops overstating them.
- **Four fall back to New without VMU.** Crazy Taxi and Spawn have no heap
  initializer slot: the game uses fixed RAM, so each needs a reviewed RAM-map
  plan, the method Crazy Taxi 2 and House of the Dead 2 already use. Dead or
  Alive 2's heap family is unresolved; Zombie Revenge needs its six-input Maple
  layout.
- **Blue Stinger is the only game with no Background route** (Maple driver
  family unresolved, no SDK SCI family).
- **19 games are not checked yet:** the first bundler skipped Windows CE and
  CD-audio games. Bundler v2 collects them; that is the largest unknown.

## Regenerate

```sh
python3 tools/library_compat_table.py Library-startup-*.zip --work PRIVATE_DIR \
    --stage-elf build/native-background-compact/stage.elf \
    --output PRIVATE_DIR/table.json --table PRIVATE_DIR/table.md
```

Then replace the table above with `table.md`. Pass every part from every
upload; runs are merged and repeats listed once.
The JSON report holds library paths and stays private; this table holds titles,
product numbers and sizes only.
