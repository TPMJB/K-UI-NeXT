# Native loader family expansion

This candidate extends shared SDK detection and startup handling. It does not
select the new behavior by game title or executable hash. The original
executables below exercise the new families; other revisions still need their
own complete discovery and live ownership checks.

| New test candidate | Shared change |
| --- | --- |
| Sonic Adventure | Early SDK exit pair combined with the complete compact executable loader; bounded dependent literal pools |
| Silver | Verified trailing bootstrap reclamation for the direct allocator, with a separately proved startup P2 lock normalizer and coherence gate |
| Quake III Arena | Complete terminal firmware-check routine and PVR literal-pool ownership |
| Sega Smash Pack | Same terminal firmware-check family and PVR literal-pool ownership |
| Toy Commander | Same terminal firmware-check family with the ordinary SDK exit pair |

These are new console test candidates. Original instruction execution,
structural discovery and linked-code validation do not establish successful
gameplay or durable saves on a Dreamcast. The package's validation report binds
the evidence to the delivered binaries.

## Install and test

Merge the package's root `KUI` folder onto the SD root. Use SCI, Background On,
New, Auto encoding, CD music Off, RAM patches Off and virtual VMU On. Keep the
selected physical VMU slot empty. A2 remains the default; the A1 selector is
available for games which require it. Use the ordinary root modules first.

Start with Sonic Adventure and Silver. For each, check a cold boot, controller
response, a scene transition, save completion, then a full power-off and reload.
After that, try Quake III, Smash Pack and Toy Commander using the same settings.
Record the displayed build, chosen slot and earliest failure. A complete
diagnostic photograph is useful if a launch or save refuses.

Regress HOTD2 with the same scene and slot as the previous working build,
Time Stalkers from an image, and EGG save/load. Physical-disc regressions remain
Power Stone 2 and Berserk, with A1 selected for Berserk. The existing Games scan
repair and current main's library tabs, favorites and optional session controls
remain included. Scan through START → Library options → Scan for changes.

The detector epoch is now 8. Old mapping records are rejected and regenerated
from the current executable on the next launch. This can add a first-launch
scan; cards, saves and journals retain their existing paths. No card formatting
or Python installation step is part of this update.

## Memory and validation boundaries

The ordinary Background worker remains 72 KiB, with a 3 KiB stack, a complete
284 KiB lease and the full 192 KiB read-ahead cache. Equivalent descriptor and
metadata checks were factored to fit those existing bounds. The optional
session-control modules retain their separate 112 KiB worker, 4 KiB stack and
324 KiB lease, also with the full cache.

The supplied 33-original corpus distinguishes raw structural/transport passes
from immutable metadata resolution. The trial expansion preserves all former
passes and adds the five raw candidates above. Tony Hawk's Pro Skater 2 also
resolves metadata, but its overlapping executable/heap placement still refuses;
it is not an additional playable-game claim. Final package counts and source
and artifact hashes are recorded in the accompanying evidence.

All eight historical allocator originals are now available, including the
Grandia II and Record of Lodoss War inputs recovered from the supplied archive.
Their fresh records and original allocator checks replace the earlier
missing-input limitation. Records are generated by the production detector;
old records are not relabeled with the new epoch. No retail executable bytes
belong in a source or evidence package.

## Remaining work toward universal coverage

Blue Stinger needs an older Maple driver, allocator and exit family. MDK2 has
a real P2 startup lock conversion with a different caller sequence from
Silver's; it remains refused until that complete sequence and its exit data
roles are proved. Generator 2 also retains an unproved formatter-pool data
role. Neither receives a partial admission.

Soul Reaver and Tony Hawk's Pro Skater 2 still need an executable-lifetime and
placement proof. Custom allocators and reviewed arena ownership remain
separate work for other titles. A refusal of the shared virtual-VMU path does
not classify the existing VMU-Off or Standard reader paths as incompatible.
CDDA, physical-disc handoff and optional return/disc switching retain their
own compatibility boundaries. Time Stalkers' repaired continuation applies to
image launches; its physical-disc virtual-VMU handoff remains unsupported.
