# Experimental 2048-byte GDI test

K-UI has a development build for comparing 2048-byte Mode 1 GDI backing tracks
with raw GDI and an original retail disc. Its host converter writes a new
folder and preserves raw audio. Data tracks use about 12.9% fewer bytes.

This is a hardware test, with no measured speed or compatibility claim yet.
Full raw-data requests from cooked tracks are unsupported. Keep the original
dump, back up KUI, and install this build's matching runtime and Apps together.
The accepted K-UI 1.7 SCI allowance remains in place.

See [installation and comparison instructions](release-v1.7-2048-test.md).
Report title/region, build ID, storage connection, reader mode, three timings
and FMV/audio observations. Public 1.7 does not launch converted backing tracks.
