The boot/recovery menu and SD runtime draw their first screen, then submit firmware `CD_CMD_STOP` before creating the I/O worker. The command uses the existing bounded command adapter: three seconds, then one second for abort recovery. It refuses active DMA and a poisoned adapter. Cleanup ignores held B, and it submits no disc INIT, TOC or read command. Bus/syscall setup is separate from media initialization. The pinned KOS stop command is used directly because its convenience spin-down wrapper has no timeout.

A firmware status syscall cannot guarantee unseen firmware motor behavior, and physical spin-down timing needs console testing.
