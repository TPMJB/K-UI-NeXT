# 1.7 SCI release baseline — 2026-10-04

## Owner decision

The owner reports that the latest SCI comparison has unclear audio, with
audio/video synchronization uncertain, and requests **release 1.7 with the
prior SCI fix**, fresh artwork and release announcements. Their exact
instruction is:

> As far as this sci test goes, it's a bust. The audio isn't clear at all.
> Not sure if it's in sync with the video. The last test seemed to be as
> good as it gets for the audio sync.
>
> So let's make a release 1.7 with the prior SCI fix. Generate new artwork
> as before and really drove home how awesome it is with all the work we put in

This records a qualitative owner decision. It does not establish a measured
frame rate, audio-quality metric or synchronization result for the released
binary.

## Existing console evidence

On `6f14bc529472`, the owner identified the photographed run as ARMADA.
The report records guard 0, 24,657 DMA and 7,058 polled receptions, 7,174
token yields, two CRC errors and zero token/foreign errors. Nonzero yields
confirm that token slicing was active; unequal-duration session totals do
not establish a throughput improvement.

The owner described ARMADA as a little better and Worms Armageddon as
improved in some respects, while Worms' intro audio led video by roughly
half a second. The later rejection favors that earlier tradeoff; it does
not erase its recorded offset or prove perfect synchronization.

The earlier [256-byte design and host validation](ce-token-slicing-2026-10-04.md)
and [256-byte console result / 512-byte comparison](ce-token-512-2026-10-04.md)
remain the detailed records. The historical ATA candidate record describes
its then-pending SCI512 test; this owner decision supersedes that pending
status for 1.7 while retaining ATA's hardware-untested status.

## Reporting boundary

Release notes separate owner console observations, diagnostic storage rates
and host validation. No universal game compatibility, exact audio/video
synchronization, full-speed Windows CE playback, ATA hardware acceptance or
ATA DMA claim follows from this release selection.
